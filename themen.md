# Themenliste

Der tägliche Lauf nimmt die obersten offenen Themen (`- [ ]`), macht daraus Videos und hakt sie ab:
`- [x] Thema → videos/NNN-name (geplant JJJJ-MM-TT HH:MM)`.
Eigene Ideen einfach als neue Zeile `- [ ] …` eintragen – ganz oben werden sie zuerst genommen.
Jedes Thema wird vor dem Video recherchiert; stimmt ein Fakt nicht, wird das Thema angepasst oder übersprungen.
